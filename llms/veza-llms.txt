# Veza

> Veza is an identity security platform. Its Open Authorization API (OAA) lets
> you publish identity, resource, and authorization metadata from custom or
> unsupported applications into the Veza Entity Catalog, making them searchable
> and governable alongside natively supported integrations. Authentication is a
> per-tenant API key sent as a bearer token; all calls target the customer's own
> Veza tenant host (https://<tenant>.vezacloud.com).

## API surface

- Custom providers: /api/v1/providers/custom
- Data sources: /api/v1/providers/custom/{provider_id}/datasources
- Push metadata: /api/v1/providers/custom/{provider_id}/datasources/{data_source_id}:push
- Assessment queries: /api/v1/assessments/queries
- Reports (preview): /api/preview/assessments/reports
